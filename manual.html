操作手冊

從「期望售價」逐層回推平台手續費、FBA費用、當地稅務費用、退貨風險與金流手續費，換算台幣後扣除頭程運費，算出你能開給供應商的最高／最低採購價格。美國站（USD）與日本站（JPY）並排試算，所有數字都是可調整的起始值。

操作步驟

  1. 先在頂部選好出貨模式（FBA／FBM）——FBA會計入「FBA費用」滑桿；FBM則不套用該費用
  2. 先點一個貼近你商品的品類範例按鈕（居家收納／3C配件／戶外露營／寵物用品／美妝保養），會套用該品類對應的售價、費率與運費假設；之後可以再自行微調任何一個滑桿
  3. 「共用假設」裡的兩個安全margin套用在美國站與日本站兩邊，margin留得越多，代表安全利潤空間越大，能接受的採購成本上限就越低
  4. 美國站／日本站兩張卡片各自的滑桿調整後，卡片內的瀑布式帳本會即時重算每一層扣除，最下面兩張卡片是最終建議採購價格
  5. 不知道每件頭程運費該填多少時，可以用卡片內的「頭程運費小工具」，輸入總運費與件數，按「帶入每件運費」自動算好填入
  6. 想重新開始，按頁尾「重設為基準假設」會清掉所有調整，回到中性起始值
「平台淨利率」徽章依門檻分三級：≥20% 健康、10–20% 偏薄、<10% 偏低；若運費已侵蝕全部收益、或安全margin下已無採購空間，卡片下方會出現紅色警示。

請 AI 診斷目前的定價與採購策略

沒有 API 金鑰也能用：直接按「改用規則式健檢」，會依兩個市場目前的淨利率與採購空間，組出對應的健檢建議，不需要連網。

想要更貼近你情境的診斷，可以展開「AI 診斷設定」，選擇服務商（Claude／OpenAI／Gemini／OpenRouter）並填入你自己的 API 金鑰，按「請 AI 診斷目前的方案」。

診斷區塊上方有 5 個「診斷角度」快速按鈕，點選後會把對應的提示文字帶入下方文字框：

  • 定價健康度：評估目前兩站定價是否留有足夠利潤緩衝
  • FBM或FBA划算：比較兩種出貨模式對利潤的影響
  • 頭程運費侵蝕：分析運費占最終採購空間的比例，並給降低建議
  • 退貨風險保守估算：評估退貨風險假設是否足夠保守
  • 美日兩站優先順序：建議該優先投入哪個市場
文字框內容可以自行編輯或清空，不一定要用按鈕帶入的範本。AI 呼叫失敗時（例如金鑰無效）會自動退回規則式健檢，不會沒有內容。

匯出 PDF

頁面右上角按「📄 匯出 PDF」，會開啟瀏覽器的列印視窗，選「另存為 PDF」即可把目前的試算內容存成 PDF 檔。匯出時會自動：

  • 把共用假設、美國站與日本站的完整瀑布帳本整理成一份報告（畫面上的互動元件不會出現在報告裡）
  • 加上浮水印與產生時間戳記，提醒這份輸出是估算工具的結果，不是正式財務報表
如果曾經產生過 AI 診斷結果，該段診斷文字也會一起出現在匯出的 PDF 裡；沒有產生過就不會出現這個區塊。
